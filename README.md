# GeoDetective

Браузерная игра-детектив: тебя «забрасывает» в 360°-панораму реального места, нужно осмотреться, собрать улики и отметить на карте, где ты находишься.

## Как это работает

- 5 локаций (Индонезия, Швейцария, Германия, США, Россия), в каждой 2–3 точки, между которыми можно переходить по стрелкам.
- Улики открываются по мере осмотра: «Атмосферный след», «Гео-сигнатура», «Триангуляция». За подсказки снимаются очки.
- Догадка ставится кликом по карте мира; чем ближе к настоящей точке, тем больше очков (до 5000 за раунд).
- Тёмная и светлая тема.

## Запуск

Демо: https://qqqflame.github.io/geodetective/

Игра — один файл без сборки. Открой `index.html` в браузере. Нужен интернет: панорамы и просмотрщик подгружаются по сети.

## Из чего сделано

- [Pannellum](https://pannellum.org/) — просмотр 360°-панорам.
- Панорамы — свободные снимки с Wikimedia Commons (CC BY / CC BY-SA); на экране результата есть ссылка на страницу каждого снимка с автором и лицензией.
- Карта мира — SVG, нарисованный вручную.

## Планы

- Карта на Leaflet + OpenStreetMap вместо SVG.
- Зум и полноэкранный режим панорамы, компас направления взгляда.
- Mapillary как второй источник панорам.
